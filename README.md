# MD 提词器

透明悬浮的 Markdown 提词器，用于演示/直播时把 `.md` 文档当提词稿用。窗口置顶、背景透明，可以叠在共享的窗口/摄像头画面附近而不遮挡太多内容。

## 功能

- 打开/拖入 `.md` / `.txt` / `.docx` 文件（`.docx` 用 mammoth 转换，`.txt` 按纯文本显示，不会被误当 Markdown 解析）
- 🔄 一键重新读取当前文件（外部改过内容后刷新用）
- 自动滚动，速度以"字/分钟"为单位，根据实际排版结果换算成滚动速度
- 字号、透明度、镜像翻转可调；调字号或拖拽缩放窗口都会保持住当前阅读位置，不会跳到别处
- 🎨 一键识别窗口背后的真实背景色，自动切换深色/浅色文字与蒙层，兼顾清晰与低调
- 鼠标穿透模式：正文区域可以穿透点击到下面的窗口，工具栏保持可点
- 系统托盘图标，可在工具栏被隐藏或窗口被最小化后随时找回（`Ctrl+Alt+R` 同样效果）

## 运行

### 日常使用（不用命令行）

首次使用需要先装一次依赖：

```bash
npm install
```

装好后，双击项目里的 `启动提词器.vbs`（或桌面上的"MD提词器"快捷方式，如果已创建）即可静默启动，不会弹出黑框命令行窗口。

### 开发 / 命令行运行

```bash
npm install
npm start
```

也可以直接传入文件路径启动：

```bash
npm start -- path/to/script.md
```

## 快捷键

全局快捷键（窗口无需处于前台）：

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Alt+Space` | 播放 / 暂停 |
| `Ctrl+Alt+↑` / `Ctrl+Alt+↓` | 调节滚动速度 |
| `Ctrl+Alt+T` | 切换鼠标穿透 |
| `Ctrl+Alt+H` | 显示 / 隐藏工具栏 |
| `Ctrl+Alt+O` | 打开文件 |
| `Ctrl+Alt+R` | 从最小化恢复窗口 |
