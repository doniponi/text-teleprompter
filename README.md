# 文本提词器

[简体中文](README.md) | [English](README.en.md)

一个透明悬浮的桌面提词器：窗口置顶、背景透明，可以叠在共享的窗口、摄像头画面、PPT 附近，让你一边看稿一边保持视线接近镜头/观众，而不用低头看手机或另一块屏幕。

支持 Markdown（`.md`）、纯文本（`.txt`）、Word（`.docx`）三种文档格式。

## 这个工具适合什么场景

- **直播 / 短视频口播**：把逐字稿或提纲挂在摄像头旁边，边看边说，观众看不到你在读稿
- **视频号 / 录课 / 录产品讲解视频**：需要长时间对着镜头说话，又怕忘词或语序混乱
- **线上会议分享屏幕**（腾讯会议 / Zoom / Teams）：想要提词提示，但不希望被共享的画面挡住或露出黑底提词器
- **路演 / 演讲彩排**：把讲稿或大纲叠在幻灯片编辑器/预览窗口旁边，边练边看
- **多语言翻译或双语播报**：文档只在自己的窗口里可见，共享画面时不会被别人看到

如果你只是想安安静静地看一份文档滚动播放，而不想被这份文档本身挡住你正在做的事，这个工具就是为这个需求做的。

## 功能

- 打开 / 拖入 `.md`、`.txt`、`.docx` 文件（`.docx` 用 mammoth 转换成排版好的内容，`.txt` 按纯文本显示，不会被误当 Markdown 语法解析）
- 🔄 一键重新读取当前文件（文档在外部被改过之后，不用重新打开也能刷新）
- 自动滚动，速度以"字/分钟"为单位，会根据当前字号和窗口宽度实际排版的结果换算成滚动速度，而不是拍脑袋估的
- 字号、透明度、镜像翻转（配合提词器玻璃反光板使用）均可调；调整字号或拖拽缩放窗口时会保持住当前阅读位置，不会跳到文档的别处
- 🎨 一键识别窗口背后的真实背景颜色，自动在深色 / 浅色文字之间切换，兼顾清晰可读和视觉上的低调
- 鼠标穿透模式：正文区域可以让鼠标点击穿透到下面的窗口（比如继续操作被挡住的应用），工具栏本身始终保持可点击，不会因为穿透而找不到出口
- 系统托盘图标 + 全局快捷键：工具栏被隐藏、窗口被最小化后，都能随时找回，不依赖窗口本身处于前台

## 下载与运行

### 直接下载（推荐，不用装开发环境）

前往 [Releases](https://github.com/doniponi/text-teleprompter/releases) 页面下载：

- **Windows**：`文本提词器-x.x.x.exe`，双击即可运行，免安装、不需要 Node.js
- **macOS（Apple Silicon / M 系列芯片）**：`文本提词器-x.x.x-arm64-mac.zip`
- **macOS（Intel 芯片）**：`文本提词器-x.x.x-x64-mac.zip`

macOS 版解压后是 `.app`，因为没有付费的 Apple 开发者证书签名，第一次打开时系统会提示"无法验证开发者"——右键点 app 选"打开"（而不是双击）即可绕过这个提示。macOS 版目前只在 CI 里做过启动/点击/滚动的自动化验证，还没有人在真机上完整用过，如果遇到问题欢迎反馈。

### 从源码运行 / 开发

首次使用需要先装一次依赖：

```bash
npm install
```

日常使用可以双击项目里的 `启动提词器.vbs`（或桌面上创建的"文本提词器"快捷方式）静默启动，不会弹出命令行窗口。

命令行运行 / 调试：

```bash
npm install
npm start
```

也可以直接传入文件路径启动：

```bash
npm start -- path/to/script.md
```

### 自行打包成 exe

```bash
npm run build:win
```

打包结果在 `dist/文本提词器-<版本号>.exe`，免安装单文件，可以直接分发。

## 快捷键

全局快捷键，窗口不在前台、甚至处于鼠标穿透状态时也能用：

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl+Alt+Space` | 播放 / 暂停自动滚动 |
| `Ctrl+Alt+↑` / `Ctrl+Alt+↓` | 调节滚动速度 |
| `Ctrl+Alt+T` | 切换鼠标穿透 |
| `Ctrl+Alt+H` | 显示 / 隐藏工具栏 |
| `Ctrl+Alt+O` | 打开文件 |
| `Ctrl+Alt+R` | 从最小化恢复窗口 |
| `Ctrl+Alt+C` | 恢复默认文字颜色/透明度 |

在窗口正文区**快速右键点两下**（双击右键）也能直接切换工具栏显示/隐藏，不用记快捷键。

工具栏被隐藏或窗口最小化后找不到入口时，也可以从系统托盘图标（任务栏"显示隐藏的图标"里，一个陶土色 T 加向上箭头的方块）里操作，托盘菜单里有播放/暂停、打开文件、重新读取当前文件、恢复穿透、恢复默认外观、重置窗口位置、显示窗口、退出等选项。
